# V3 React + Three.js 純鏡頭流程

V3 使用連續 3D 場景，不使用照片交叉淡化。MP4 本身只包含車輛、停車場與第一人稱相機運動；掃描提示、品質條、異常框與六區車圖均保留給 Flutter 疊加。

## 10 秒測試流程

| 時間 | 鏡頭 | Flutter 預留事件 |
| --- | --- | --- |
| 0–3.15 秒 | 左側定點掃描，垂直位移固定為零 | 辨識左側、品質鎖定、左側完成 |
| 3.15–7.5 秒 | 沿車頭方向平滑走動，僅此段保留極輕微步行感 | 左側填綠、提示移動至車頭 |
| 7.5–10 秒 | 車頭定點掃描，垂直位移固定為零 | 自動辨識車頭、啟動品質進度 |

精確 frame 範圍與 UI 安全區域以 `camera-timeline-v3.json` 為準。

## 正式影片延伸方式

正式全流程沿用同一輛車、同一 HDRI 與同一鏡頭控制器，延伸為：左側、車頭、右側、刮痕靠近與退開、車尾、前座、後座污漬。各區段由固定 frame 事件通知 Flutter 更新六區狀態，不要求使用者手動切換區域。

## 輸出

```powershell
npm run qa:camera-v3
npm run render:camera-v3
```

輸出檔：`output/inspectflow-threejs-camera-test-v3-10s.mp4`

- 1920×1080
- 60 FPS、600 幀、10 秒
- H.264 MP4
- 無燒錄 UI
