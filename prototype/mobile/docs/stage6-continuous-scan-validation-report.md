## 流程與資料驗證

- 單一工作階段可完成六個不重複區域，並拒絕重複完成同一區。
- 建議順序維持右側、車頭、左側、車尾、前座、後座，但控制器可接受任意尚未完成的自動辨識區域。
- 每區從穩定到品質鎖定採 80 毫秒共十段，設計值為 0.8 秒。
- 左側刮痕會保存廣角及中央、左側、右側三個補充視角。
- 車外完成後會顯示開門提示，再進入前座與後座掃描。
- 後座污漬會在品質鎖定後保存，完成畫面保留左側與後座兩個異常標記。
- 直向摘要與本機輸出包含 scratch 與 stain 兩筆 Finding，會員端不顯示歸責或費用判定。
- 隱藏 Demo 控制器保留完整重播、下一事件及重設三項操作。

## 待人工補驗

錄製展示影片前，仍需在可操作的 Chrome 或 Android 裝置完成一次約 24 秒不中斷演練，確認：

1. 本機影片在實際瀏覽器可連續播放且聲畫面不跳格。
2. 直向總覽進入橫向掃描、完成後返回直向的實機方向切換。
3. 長按 Prototype 標示後，重播、下一事件與重設均可重複操作。
4. 六區完成後可自動離開橫向掃描並直接開啟摘要，六區與兩筆異常內容正確。

這些項目是瀏覽器／裝置層級的視覺與操作補驗，不影響目前程式測試、Web 建置與離線素材完整性結論。

## 已知產品邊界

- 相機、車體辨識、品質判斷與異常判讀皆由本機影片及 JSON 時間軸模擬。
- 0.8 秒是對準後的單區品質鎖定設計值，不代表正式模型效能或全車掃描時間。
- 六區與掃描順序仍是產品設計假設，需取得官方規範後調整。
- AI 不在會員端自動判定索賠責任或賠償金額。
