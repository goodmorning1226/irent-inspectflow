## 已知限制

- 本次沒有 Android 裝置，因此未驗證實體手機的兩種橫向持握與系統旋轉動畫。
- 內建瀏覽器自動控制連線無法建立；完整互動由 Flutter Widget／整合測試驗證，並另外確認 Chrome 可實際啟動 App。
- Prototype 使用固定影片、假資料與時間軸，不代表正式 AI 模型準確率或 iRent 系統介接已完成。
- Web 瀏覽器無法由 App 強制旋轉實體螢幕，展示時需要手動使用對應的直向或橫向視窗。
