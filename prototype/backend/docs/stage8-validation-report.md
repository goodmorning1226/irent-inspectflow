## 4. 程式層可及性與邊界檢查

- 案件表格列可使用 Enter 或 Space 開啟。
- 主要操作使用原生 button、input、select、textarea、details 及 summary。
- 全站提供 `:focus-visible` 焦點樣式及 `prefers-reduced-motion` 降低動態設定。
- 影像放大視窗具有 dialog 語意、Escape 關閉及焦點恢復。
- 缺少影像、空篩選、未知路由與全域錯誤皆有可理解的替代畫面。
- AI、KPI、信心、ETA、逾期及派工推薦均標示為 Prototype 或展示假資料。
- 索賠畫面不提供自動歸責或自動賠償金額。

## 5. 尚未完成的瀏覽器驗證

本次工作環境沒有任何可用的瀏覽器連線，因此以下項目尚未實際執行，不標示為通過：

- 1024×768、1280×800、1440×900、1920×1080 的逐頁視覺檢查。
- 瀏覽器中的文字溢出、影像裁切、Sticky、捲動區與元素重疊檢查。
- 使用 Tab、Shift+Tab、Enter、Space、Escape 完成實際鍵盤走查。
- S02 與 S03 的不中斷瀏覽器操作及三分鐘展示演練。
- 代表性頁面截圖與視覺差異紀錄。

原始碼已針對上述四種桌面寬度建立 1350、1100、760 三層 responsive 規則；1024 寬度會切換單欄案件及任務工作區，案件表格與任務佇列則保留水平捲動。然而，在可用瀏覽器完成實際確認前，不能視為視覺驗收完成。

## 6. 建議瀏覽器補驗順序

1. 以 1440×900 檢查車況比對清單、S03 比對詳情、任務分配與索賠清單。
2. 以 1024×768 檢查單欄詳情、表格與索賠清單的水平捲動。
3. 以 1280×800 檢查 S06 清潔任務與 S07 維修任務的人員分配。
4. 以 1920×1080 檢查最大內容寬度及 Sticky 摘要／審查欄。
5. 重設 S06 與 S07，分別改派清潔及維修人員。
6. 重設 S03 與 S07，確認索賠清單嚴重度排序並各送出一筆人工結論。
7. 全程以鍵盤重走三個主導覽、清單列、派工選項與索賠表單。
