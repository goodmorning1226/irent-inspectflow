# 簡報版面與字級標準

適用檔案：`slide/index.html`。字級以 1600 × 900 投影片原始畫布為準；瀏覽器展示時整張投影片會等比例縮放。

| 層級 | 字級 | 用途 |
| --- | --- | --- |
| 封面主標題 | 94px | 作品名稱 |
| 封面副標題 | 32px | 產品描述 |
| 頁面標題 | 48px | 每頁主要標題 |
| 小標題 | 24px | 分組標題、功能名稱、圖片標題 |
| 內文 | 20px | 說明段落、條列、重點框、流程節點名稱 |
| 輔助文字 | 18px | 章節標籤、表格、摘要欄位、圖片說明、流程補充、註記、頁碼 |
| 數字展示 | 64px／32px | 指標數值／裝飾性編號，不用於一般文字 |

- 字級集中使用 CSS 變數，元素不另設行內字級。
- 一般頁面採白色背景，左上角不加裝飾橫線。
- 一般頁面留白：上方 64px、左右 86px、下方 58px；頁面標題下方留白 28px。
- 內文行高 1.45，頁首說明段落行高 1.5，輔助說明行高 1.4；表格行高 1.45。
- 表格欄位標題統一使用深藍底、白字與粗體；一般重點框用青色，警示與責任邊界用橘色。
- 每段通常強調一至兩個關鍵片語，以 800 字重呈現；不將整段加粗。
- 封面保留背景圖片與漸層遮罩。
- 最低字級 18px 適用於 HTML 文字；圖片內原有文字屬於圖片素材，無法透過 CSS 調整。

## 表格與文字框

- 表格統一 1px 淺灰框線、深藍底白字表頭、白色與淺灰交替列底色；儲存格留白為上下 14px、左右 18px。
- 無表頭的資料表採左側深藍欄名，對照表採頂部深藍表頭；提案概述已改成同一套標準表格。
- 提案摘要保留原本表單式設計：淺色欄名、2px 深色框線、上下 15px 與左右 18px 留白。
- 文字框統一 12px 圓角、1px 淺灰框線、左側 4px 青色線、上下 18px 與左右 24px 留白，上方間距 24px。
- 警示文字框沿用相同尺寸，改用橘色線與淡橘背景。
- 流程卡片統一淺灰底、12px 圓角、1px 框線與頂部 4px 青色線，內部留白 18px。
- 圖片框與影像提示標籤統一 12px 圓角。

## 章節進度條

- 除提案摘要外，每頁頂部顯示章節名稱與頁面圓點（不列封面章節）；目前章節用青色粗體，目前頁面用青色實心圓點。
- 章節文字固定 16px，為使用者指定的最低 18px 字級例外。
- 所有進度條以灰色／青色文字搭配淺灰背景與分隔線。
- 有進度條的一般頁面上方留白改為 94px，摘要維持 64px。

- 進度條貼齊投影片上緣，背景橫跨左右邊界，採淺灰底與底部 2px 分隔線、無圓角；內部左右留白 86px，章節文字與圓點在同一行排列；各章節標題依序編號 1 至 7；項目之間的橫線伸展填滿空隙，貼齊前項圓點與後項標題。

- 三欄表格統一20%／40%／40%；四欄表格18%／其餘三欄均分；兩欄資料表28%／72%；左右對照表等寬。
